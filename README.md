# Unstuck: Product Analyzer

Shopify app that finds underperforming products, diagnoses why they don't sell, applies fixes, measures the effect, and discounts only as a last step. Full plan: [docs/PLAN.md](docs/PLAN.md).

## Stack

- Next.js (App Router, TypeScript)
- Tailwind CSS

No other dependencies are added without the owner's approval.

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.
